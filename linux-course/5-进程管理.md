# 第 5 课：进程管理

## 目标

学会查看、管理正在运行的程序（进程）。

## 命令清单

### ps — 查看进程快照

```bash
ps                  # 当前终端的进程
ps aux              # 所有进程，详细信息
ps aux | grep nginx # 查找特定进程
ps -ef              # 另一种常用格式
```

ps aux 输出解读：
```
USER  PID  %CPU %MEM    VSZ   RSS TTY STAT START   TIME COMMAND
root    1   0.0  0.1 103460 12344 ?   Ss   06:42   0:02 /sbin/init
```
- PID：进程 ID（唯一标识）
- %CPU：CPU 使用百分比
- %MEM：内存使用百分比
- STAT：状态（S=睡眠，R=运行，Z=僵尸）

### top — 实时进程监控

```bash
top                     # 实时显示
# 按 q 退出
# 按 1 看所有 CPU 核心
# 按 M 按内存排序
# 按 P 按 CPU 排序
# 按 k 然后输入 PID 来杀进程
```

### htop — 更友好的 top

```bash
htop                    # 彩色界面，鼠标交互
# 如果没装：apt install htop
```

### kill — 终止进程

```bash
kill PID                # 礼貌地请进程退出（SIGTERM）
kill -9 PID             # 强制杀死（SIGKILL）
kill -15 PID            # 同 kill（默认）
kill -l                 # 列出所有信号
```

信号对比：
| 信号 | 数字 | 效果 |
|------|------|------|
| SIGTERM | 15 | 请求退出，进程可以清理后退出（默认） |
| SIGKILL | 9 | 立即杀死，不给清理机会 |
| SIGHUP | 1 | 重新加载配置 |

### killall / pkill — 按名杀进程

```bash
killall nginx           # 杀所有名为 nginx 的进程
pkill -f "python app"   # 按完整命令行匹配
pkill -u username       # 杀某用户的所有进程
```

### bg / fg / jobs — 前后台切换

```bash
sleep 1000 &            # & 放到后台运行
jobs                    # 查看后台任务
fg %1                   # 把任务1拉回前台
bg %1                   # 把任务1放到后台继续运行
Ctrl+Z                  # 暂停当前前台任务
Ctrl+C                  # 终止当前前台任务
```

### nohup — 退出终端不停

```bash
nohup long-task.sh &    # 退出 SSH 后继续运行
nohup long-task.sh > output.log 2>&1 &
# > output.log = 输出到文件
# 2>&1 = 错误也输出到同一个文件
```

## 关键概念

### 什么是进程

运行中的程序叫进程（process）。每个进程有：
- 唯一的 PID
- 一个父进程（PPID）
- 一个用户（哪个用户启动的）
- 占用一些内存和 CPU

### 进程 vs 线程

一个进程可以包含多个线程（thread）。比如一个 Web 服务器进程可以同时处理多个请求，每个请求一个线程。

### 僵尸进程

进程执行完但父进程还没回收。`ps aux` 中 STAT 为 `Z`。不占资源但 PID 不释放。

### 守护进程 (daemon)

在后台持续运行的服务进程，不以终端为依赖。比如 Docker、MySQL、SSH。名字常以 `d` 结尾（dockerd、mysqld、sshd）。

## 实战演示

```bash
# 看看所有进程
ps aux | head -20

# 找 Docker 相关进程
ps aux | grep docker

# 开个后台任务
sleep 300 &
# 输出：[1] 12345   （1是任务号，12345是PID）

# 查看后台任务
jobs

# 找到并杀掉
kill 12345
jobs
# 应该显示 Terminated

# 查看系统实时状态
top
# 按 q 退出
```

## 练习

1. 用 `ps aux` 列出所有进程，数一数有多少个
2. 找出 PID 为 1 的进程是什么（它是所有进程的祖先）
3. 启动 `sleep 120 &`，用 jobs 查看，用 kill 终止
4. 用 `top` 观察内存最高的进程是哪个
