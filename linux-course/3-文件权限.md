# 第 3 课：文件权限

## 目标

理解 Linux 的读写执行权限，能正确设置文件和目录权限。

## 先看懂 ls -l 输出

```bash
ls -l
# -rw-r--r-- 1 root root  128 May 27 07:00 file.txt
```

拆解每一部分：

```
-   rw-   r--   r--    1   root  root  128  May 27 07:00  file.txt
|   |      |     |     |    |     |     |    |
类型 所有者 组 其他人 链接数 所有者 组 大小 日期 文件名
```

### 第一部分：文件类型

| 符号 | 含义 |
|------|------|
| `-` | 普通文件 |
| `d` | 目录 |
| `l` | 符号链接（快捷方式） |

### 第二部分：权限

`rwxr-xr-x` 分成三组，每组三个字母：

| 字母 | 文件 | 目录 |
|------|------|------|
| `r` (read) | 可读取内容 | 可列出文件列表 |
| `w` (write) | 可修改内容 | 可在里面创建/删除文件 |
| `x` (execute) | 可作为程序运行 | 可 `cd` 进入 |

**三组含义：**

```
rwx    r-x    r-x
 |      |      |
所有者   组    其他人
(u)    (g)   (o)
```

例：`rw-r--r--` = 所有者可读写，组只读，其他人只读。

## chmod — 修改权限

### 字母方式（适合新手）

```bash
chmod u+x file.sh      # user + x = 给所有者加执行权限
chmod g-w file.txt     # group - w = 去掉组的写权限
chmod o+r file.txt     # other + r = 给其他人读权限
chmod a+x script.sh    # all + x = 所有人可执行
chmod u+rwx file       # 所有者全权限
```

### 数字方式（更快，记住后常用）

| 数字 | 权限 | 二进制 |
|------|------|--------|
| 0 | --- | 000 |
| 1 | --x | 001 |
| 2 | -w- | 010 |
| 3 | -wx | 011 |
| 4 | r-- | 100 |
| 5 | r-x | 101 |
| 6 | rw- | 110 |
| 7 | rwx | 111 |

常用组合：

```bash
chmod 755 script.sh    # rwxr-xr-x  脚本/程序
chmod 644 file.txt     # rw-r--r--  普通文件
chmod 700 secret.key   # rwx------  私密文件
chmod 600 id_rsa       # rw-------  SSH 私钥
chmod 777 public/      # rwxrwxrwx  完全开放（不安全）
```

## chown — 修改所有者

```bash
chown user file.txt             # 改所有者
chown user:group file.txt       # 同时改所有者和组
chown -R user:group dir/        # 递归改整个目录
```

## 实战演示

```bash
# 创建文件看看默认权限
touch test.txt
ls -l test.txt
# 默认: -rw-r--r-- (644)

# 创建脚本
echo '#!/bin/bash' > hello.sh
echo 'echo Hello' >> hello.sh
cat hello.sh

# 直接运行
./hello.sh
# 报错：Permission denied

# 加执行权限
chmod +x hello.sh
ls -l hello.sh
# -rwxr-xr-x

# 现在能运行了
./hello.sh

# 改为只有自己能读写执行
chmod 700 hello.sh
ls -l hello.sh
# -rwx------

# 清理
rm test.txt hello.sh
```

## 关键概念

### 目录权限特殊之处

- 目录需要 `x` 权限才能进入（cd）
- 目录需要 `r` 权限才能列出文件（ls）
- 目录需要 `w` 权限才能在里面创建/删除文件
- 删除文件不需要文件本身的权限，需要**目录的写权限**

### 为什么 SSH 私钥必须是 600

```bash
# SSH 会拒绝权限不对的私钥
chmod 644 ~/.ssh/aliyun  # SSH 会警告 "Permissions are too open"
chmod 600 ~/.ssh/aliyun  # 正确
```

### 最大权限 777 很危险

`chmod 777` 让任何人都能修改你的文件。服务器上绝对不要对重要文件用 777。
