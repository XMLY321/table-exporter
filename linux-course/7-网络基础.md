# 第 7 课：网络基础

## 目标

学会查看网络状态、测试连通性、理解端口。

## 命令清单

### ip — 查看网络接口

```bash
ip a                    # 所有网络接口和 IP
ip addr                 # 同上
ip route                # 路由表
```

输出中找 `inet`：
- `127.0.0.1` — 本地回环（本机自己连自己）
- `172.x.x.x` — Docker 内网
- `47.98.x.x` — 公网 IP

### ping — 测试连通性

```bash
ping 47.98.187.156          # 一直 ping，Ctrl+C 停止
ping -c 4 8.8.8.8          # 只发 4 个包
ping -c 3 baidu.com        # ping 域名
```

`Ctrl+C` 后会显示统计：丢包率、平均延迟。

### curl — HTTP 客户端

```bash
curl http://47.98.187.156          # GET 请求，输出网页源码
curl -I http://47.98.187.156       # 只看响应头
curl -o file.html http://...       # 下载到文件
curl -s http://... | head          # 安静模式 + 管道
curl -X POST -d "name=test" http://...    # POST 请求
```

### wget — 下载文件

```bash
wget https://example.com/file.zip
wget -O newname.zip https://...    # 指定文件名
wget -c https://...                # 断点续传
```

### ss — 查看端口和连接

```bash
ss -tlnp                    # 所有监听的 TCP 端口
ss -tlnp | grep 80          # 谁在监听 80 端口
ss -s                       # 连接统计
```

输出：
```
LISTEN  0  128  0.0.0.0:80  0.0.0.0:*  users:(("docker-proxy",pid=5328,fd=8))
```
- `0.0.0.0:80` = 监听所有 IP 的 80 端口
- `127.0.0.1:3306` = 只监听本机（外部无法访问）

### nc — 端口测试

```bash
nc -zv 47.98.187.156 80        # 测试远程端口是否开放
nc -zv 47.98.187.156 8080      # Connection succeeded or refused
```

### dig / nslookup — DNS 查询

```bash
dig baidu.com                   # 详细 DNS 信息
nslookup baidu.com              # 简单查询
host baidu.com                  # 最简
```

## 关键概念

### 端口是什么

一台服务器上可能有多个服务：网站、数据库、图床、Docker。它们用不同的**端口号**区分：

| 端口 | 常见用途 |
|------|---------|
| 22 | SSH |
| 80 | HTTP（网页） |
| 443 | HTTPS（加密网页） |
| 3306 | MySQL |
| 8080 | 备用 HTTP |
| 5432 | PostgreSQL |

范围：0-65535。0-1023 是"知名端口"，需要 root 权限绑定。

### 公网 vs 内网

- 公网 IP（47.98.187.156）：全世界都能访问
- 内网 IP（172.19.0.x）：只有本机 Docker 容器间能访问
- 本地回环（127.0.0.1）：只有自己

### 防火墙

阿里云有两层防火墙：
1. **阿里云安全组** — 云平台层，控制台管理
2. **UFW** — 服务器系统层，`ufw` 命令管理

两层都要放开端口才能从外网访问。

### DNS

把域名翻译成 IP 的服务。你访问 `baidu.com` → DNS 查询 → `110.242.68.66` → 浏览器连接这个 IP。

## 实战演示

```bash
# 查看自己的 IP
ip a | grep inet

# 查看监听端口
ss -tlnp

# 测试本地服务
curl -s http://localhost | head -5

# 测试远程
curl -sI http://baidu.com | head -5

# 查看 DNS
host github.com

# 统计连接数
ss -s
```

## 练习

1. 用 `ss -tlnp` 列出所有监听端口，说出每个端口的用途
2. 用 `curl` 访问自己的博客和确认能访问
3. 用 `ping -c 3` 测试到 baidu.com 的延迟
4. 用 `host` 查 3 个域名的 IP
