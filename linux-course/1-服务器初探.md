# 第 1 课：服务器初探

## 目标

学会 9 个最基础的 Linux 命令，能看懂服务器状态。

## 命令清单

### whoami — 我是谁

```bash
whoami
```
显示当前登录的用户名。`root` 是超级管理员，权限最高。

### hostname — 服务器名字

```bash
hostname
```
每台服务器有个名字。阿里巴巴服务器默认是一串随机字母数字。

### cat /etc/os-release — 什么系统

```bash
cat /etc/os-release
```
Linux 有几百种发行版（Ubuntu、CentOS、Debian 等），这个文件记录了版本信息。

### uname — 内核信息

```bash
uname -r    # 只看版本号
uname -a    # 全部信息
```
Linux 内核是操作系统的核心。`-r` 是选项(option)，告诉命令要什么输出。

### uptime — 运行了多久

```bash
uptime
```
输出解读：`up 1:14` = 开机 1 小时 14 分。`load average` = CPU 负载，三个数值分别是 1分钟/5分钟/15分钟 平均，低于 1 表示很闲。

### pwd — 当前在哪

```bash
pwd
```
Print Working Directory。Linux 文件系统是树形结构，根目录是 `/`，root 用户的家目录是 `/root`。

### ls — 看看有什么

```bash
ls          # 简单列表
ls -l       # 详细信息（大小、权限、时间）
ls -la      # 包含隐藏文件（.开头）
ls -lh      # 人类可读的文件大小
```

### df — 磁盘还有多少空间

```bash
df -h       # -h = human readable，显示 GB 而不是字节
df -h /     # 只看根分区
```
输出：`/dev/vda3 40G 6.6G 31G` = 总 40G，已用 6.6G，剩 31G。

### free — 内存用了多少

```bash
free -h
```
`available` 是实际可用的内存，比 `free` 准确。

## 关键概念

### root 用户

Linux 超级管理员。可以删除任何文件、安装任何软件、修改任何配置。**没有撤销按钮。**

### 隐藏文件

以 `.` 开头的文件和目录是隐藏的。`ls -la` 才能看到。

常见隐藏文件：
- `.ssh/` — SSH 密钥
- `.bash_history` — 你执行过的命令历史
- `.bashrc` — shell 配置文件

### 路径

- `/` — 根目录，所有东西的起点
- `/root` — root 用户的家目录
- `/home` — 普通用户的家目录
- `/etc` — 配置文件目录
- `/var` — 日志和数据文件

## 实战演示

```bash
# 查看你当前是谁，在哪
whoami
pwd

# 查看系统整体状态
hostname
uptime
free -h
df -h

# 看看家里有什么
ls -la

# 看看整个系统
ls /
```

## 练习

1. 用 `uname -a` 查看完整系统信息
2. 用 `df -h` 看所有分区
3. 用 `ls -l /etc` 看配置目录有什么
4. 用 `cat /etc/os-release` 看完整版本信息
