# 第 8 课：服务管理

## 目标

学会用 systemctl 管理服务，看懂日志。

## systemctl — 服务管理

systemd 是 Linux 的初始化系统，负责启动、管理所有服务。`systemctl` 是操作它的命令。

### 查看状态

```bash
systemctl status docker          # 某个服务详情
systemctl status docker --no-pager   # 不进入分页模式
systemctl is-active docker       # 是否在运行
systemctl is-enabled docker      # 是否开机自启
systemctl list-units --type=service --state=running   # 所有正在运行的服务
```

### 启动/停止/重启

```bash
systemctl start nginx            # 启动
systemctl stop nginx             # 停止
systemctl restart nginx          # 重启
systemctl reload nginx           # 重载配置（不停服）
```

`reload` vs `restart`：
- reload = 重新读配置文件，不中断服务
- restart = 完全停掉再启动，会短暂断联

### 开机自启

```bash
systemctl enable nginx           # 设为开机自启
systemctl disable nginx          # 取消开机自启
systemctl enable --now nginx     # 设置开机自启 + 立即启动
```

### 查看依赖

```bash
systemctl list-dependencies docker           # docker 依赖哪些服务
systemctl list-dependencies docker --reverse # 哪些依赖 docker
```

## journalctl — 查看日志

### 基础用法

```bash
journalctl -u docker                        # 查看 docker 日志
journalctl -u docker -n 20                  # 最后 20 行
journalctl -u docker -f                     # 实时追踪（Ctrl+C 退出）
journalctl -u docker --since "1 hour ago"   # 最近 1 小时
journalctl -u docker --since today          # 今天的日志
```

### 高级过滤

```bash
journalctl -u docker -p err                 # 只看错误级别
journalctl -u docker -o json-pretty         # JSON 格式输出
journalctl --since "2026-05-27 07:00:00"    # 指定时间开始
journalctl -k                               # 内核日志
journalctl --disk-usage                     # 日志占多少空间
```

## 关键概念

### systemd 单元类型

| 后缀 | 含义 | 例 |
|------|------|-----|
| `.service` | 系统服务 | `nginx.service` |
| `.timer` | 定时任务 | `apt-daily.timer` |
| `.socket` | 套接字 | `docker.socket` |
| `.mount` | 挂载点 | `home.mount` |

### 服务状态含义

```
Loaded: loaded (/lib/systemd/system/docker.service; enabled)
Active: active (running) since ...
```

- `loaded` = 配置文件已加载
- `enabled` = 开机自启（disabled = 不自启）
- `active (running)` = 正在运行（dead = 已停止）

### Docker 容器的日志

容器服务的日志不在 journalctl，在 Docker 自己：

```bash
docker logs halo
docker logs lsky --tail=20
docker logs lsky -f              # 实时
docker compose -f /opt/lsky/docker-compose.yaml logs --tail=10
```

### 日志文件位置（非 Docker 服务）

```bash
/var/log/syslog         # 系统主日志
/var/log/auth.log       # 认证（登录）日志
/var/log/nginx/         # Nginx 日志
```

## 实战演示

```bash
# 看 Docker 服务状态
systemctl status docker --no-pager | head -20

# 看看所有运行中的服务
systemctl list-units --type=service --state=running

# 看 Docker 日志
journalctl -u docker -n 5

# 检查开机自启
systemctl is-enabled docker
systemctl is-enabled ssh

# 看 UFW 防火墙状态
systemctl status ufw --no-pager | head -5
ufw status

# 最近登录记录
journalctl -u ssh --since today
```

## 练习

1. 用 `systemctl list-units --type=service --state=running` 列出运行中的服务
2. 查看 `ssh` 服务是否开机自启
3. 用 `journalctl -u ssh -n 20` 查看 SSH 登录日志
4. 用 `docker compose -f /opt/halo/docker-compose.yaml logs --tail=10` 查看博客日志
5. 用 `docker compose -f /opt/lsky/docker-compose.yaml ps` 查看服务状态
