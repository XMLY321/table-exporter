# 第 10 课：实战 — 部署一个网站

## 目标

把你写的 HTML/CSS 页面部署到服务器上，通过公网 IP 访问。

## 方案

用 **Nginx** 做 Web 服务器，把 HTML 文件放到 `/var/www/mysite/` 下。

## 步骤

### 1. 安装 Nginx

```bash
apt update
apt install nginx -y
systemctl enable --now nginx
```

装完后浏览器打开 `http://47.98.187.156`，应该看到 Nginx 默认欢迎页。

注意：需要先在阿里云安全组放开 **80 端口**。如果之前博客（Halo）占用了 80 端口，需要先停掉或换端口。

### 2. 创建网站目录

```bash
mkdir -p /var/www/mysite
chown -R $USER:$USER /var/www/mysite
```

### 3. 写 HTML 页面

```bash
nano /var/www/mysite/index.html
```

写一个简单的页面：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的网站</title>
    <style>
        body {
            font-family: system-ui, sans-serif;
            max-width: 700px;
            margin: 60px auto;
            padding: 0 20px;
            background: #0f172a;
            color: #e2e8f0;
        }
        h1 { color: #818cf8; }
        .card {
            background: #1e293b;
            padding: 20px;
            border-radius: 8px;
            margin: 15px 0;
        }
    </style>
</head>
<body>
    <h1>👋 你好，我是 XMLY</h1>
    <p>这是我的第一个 Linux 服务器上运行的网站。</p>
    
    <div class="card">
        <h3>技能</h3>
        <p>HTML / CSS / Linux / Docker</p>
    </div>
    
    <div class="card">
        <h3>项目</h3>
        <p>表格导出助手 — 浏览器扩展</p>
    </div>
</body>
</html>
```

### 4. 配置 Nginx

Nginx 的配置文件在 `/etc/nginx/sites-available/`，创建新配置：

```bash
nano /etc/nginx/sites-available/mysite
```

```nginx
server {
    listen 8081;
    server_name _;

    root /var/www/mysite;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

启用配置：

```bash
ln -s /etc/nginx/sites-available/mysite /etc/nginx/sites-enabled/
nginx -t                    # 检查配置语法
systemctl reload nginx      # 重载配置
```

### 5. 放开端口

阿里云安全组添加规则：端口 `8081/8081`，授权 `0.0.0.0/0`。

### 6. 访问

打开 `http://47.98.187.156:8081`

## Docker 方式部署（进阶）

Halo 博客和兰空图床都是用 Docker Compose 部署的，你可以用同样的方式部署自己的网站：

```yaml
# /opt/mysite/docker-compose.yaml
services:
  web:
    image: nginx:alpine
    restart: always
    ports:
      - "8082:80"
    volumes:
      - ./html:/usr/share/nginx/html:ro
```

```bash
mkdir -p /opt/mysite/html
# 把 HTML 文件放到 /opt/mysite/html/index.html
docker compose -f /opt/mysite/docker-compose.yaml up -d
```

访问 `http://47.98.187.156:8082`

## Nginx 配置要点

### 基本结构

```nginx
server {
    listen 端口;
    server_name 域名;        # _ 代表匹配所有
    
    root 网站目录;
    index index.html;
    
    location /路径 {
        # 处理规则
    }
}
```

### 常用配置

```nginx
# 反向代理（把 /api 请求转给后端）
location /api/ {
    proxy_pass http://localhost:3000/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

# 静态文件缓存
location ~* \.(jpg|png|css|js)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
}

# 自定义 404 页面
error_page 404 /404.html;
```
