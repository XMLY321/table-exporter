# 第 2 课：文件操作

## 目标

学会创建、查看、复制、移动、删除文件和目录。

## 命令清单

### mkdir — 创建目录

```bash
mkdir test              # 创建一个目录
mkdir -p a/b/c          # 创建多层目录（自动创建中间不存在的目录）
mkdir -v folder         # 显示创建过程
```
mkdir = make directory

### touch — 创建空文件 / 更新时间戳

```bash
touch file.txt          # 创建空文件
touch a.txt b.txt c.txt # 一次创建多个
touch existing.txt      # 如果文件已存在，只更新修改时间
```

### cat — 查看文件内容

```bash
cat file.txt            # 输出全部内容
cat -n file.txt         # 带行号输出
cat a.txt b.txt         # 拼接多个文件输出
```
适合小文件，大文件用 `less` 或 `head`/`tail`。

### nano — 终端里编辑文件

```bash
nano file.txt
```
最友好的终端编辑器。操作提示在底部：
- `^O` = Ctrl+O 保存
- `^X` = Ctrl+X 退出
- `^K` = Ctrl+K 剪切当前行
- `^U` = Ctrl+U 粘贴

### cp — 复制

```bash
cp source.txt dest.txt      # 复制文件
cp -r dir1 dir2             # 复制目录（必须加 -r）
cp -v a.txt b.txt backup/   # 复制到目录里
```
`-r` = recursive，递归复制目录下所有内容。

### mv — 移动 / 重命名

```bash
mv old.txt new.txt          # 重命名
mv file.txt folder/         # 移入目录
mv 1.txt 2.txt 3.txt dir/    # 移多个文件
```

### rm — 删除

```bash
rm file.txt                 # 删除文件
rm -r folder/               # 删除目录
rm -rf folder/              # 强制删除，不确认
```

> rm -rf 没有回收站，删了就没了！

### head / tail — 看文件头尾

```bash
head file.txt               # 前 10 行
head -n 5 file.txt          # 前 5 行
tail file.txt               # 最后 10 行
tail -f /var/log/syslog     # 实时追踪日志（不断输出新内容）
```

### wc — 统计

```bash
wc -l file.txt              # 行数
wc -w file.txt              # 单词数
wc -c file.txt              # 字节数
```

## 关键概念

### 文件和目录的区别

目录是"文件夹"。`ls` 蓝色的是目录，白色是文件。`ls -l` 第一列 `d` 开头 = 目录，`-` 开头 = 文件。

### 通配符

```bash
ls *.txt        # 所有 .txt 文件
ls test?        # test1、test2 等（? 匹配单个字符）
ls [abc].txt    # a.txt、b.txt、c.txt
rm *.log        # 删掉所有 .log 文件 —— 小心！
```

### 文件命名

- **不要用空格！** 用下划线 `_` 或横线 `-` 代替
- 区分大小写：`File.txt` 和 `file.txt` 是两个文件
- 不要用中文名（个别环境下会乱码）

## 实战演示

```bash
# 创建练习目录
mkdir -p ~/linux-practice
cd ~/linux-practice

# 创建一些文件
touch note.txt readme.md
mkdir project

# 看看创建了什么
ls -la

# 写点内容到文件
echo "Hello Linux" > hello.txt
cat hello.txt

# 复制和重命名
cp hello.txt hello_backup.txt
mv hello_backup.txt renamed.txt
ls

# 统计
wc -l /etc/passwd        # 系统有多少用户账号

# 清理
cd ~ && rm -rf ~/linux-practice
```
