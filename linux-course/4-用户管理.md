# 第 4 课：用户管理

## 目标

学会创建用户、切换身份、理解 Linux 用户体系。

## 命令清单

### who — 当前谁在线

```bash
who         # 列出所有登录用户
w           # 更详细：在做什么、空闲时间
last        # 最近的登录记录
```

### id — 查看用户信息

```bash
id                  # 自己的 UID、GID、组
id username         # 查看其他用户
```

输出：`uid=0(root) gid=0(root) groups=0(root)`

root 的 uid 永远是 **0**。系统靠数字识别用户，名字只是给人看的。

### useradd — 创建用户

```bash
useradd -m username                     # 创建普通用户（-m = 创建家目录）
useradd -m -s /bin/bash username       # 指定 shell 为 bash
```

新用户在 `/home/username/` 下。

### passwd — 设置密码

```bash
passwd username     # 给别人设密码（root 可以）
passwd              # 给自己改密码
```

### su — 切换用户

```bash
su - username       # 切换用户（- 表示加载新用户的环境变量）
su -                # 不加用户名 = 切到 root
exit                # 退回上一个用户
```

### sudo — 临时借权限

`sudo` 让普通用户以 root 身份执行一条命令。

```bash
# 作为普通用户
sudo apt update             # 临时用 root 权限
sudo !!                     # 用 sudo 重复上一条命令
sudo -i                     # 变成 root shell
```

### userdel — 删除用户

```bash
userdel username            # 删用户（不删家目录）
userdel -r username         # 连家目录一起删
```

### usermod — 修改用户

```bash
usermod -aG docker username # 把用户加入 docker 组
usermod -s /bin/bash user   # 改 shell
usermod -L user             # 锁定账号
usermod -U user             # 解锁账号
```

## 关键文件

### /etc/passwd — 用户列表

```bash
cat /etc/passwd
# root:x:0:0:root:/root:/bin/bash
# 用户名:密码占位:UID:GID:描述:家目录:shell
```

密码现在存在 `/etc/shadow` 里，`x` 是占位符。

### /etc/shadow — 密码（加密）

```bash
cat /etc/shadow | head -2
# root:$y$j9T$...:16825:0:99999:7:::
# 只有 root 能读
```

### /etc/group — 组列表

```bash
cat /etc/group
# docker:x:999:user1,user2
```

## 关键概念

### root vs 普通用户

| | root | 普通用户 |
|---|------|---------|
| 家目录 | `/root` | `/home/xxx` |
| 提示符 | `#` | `$` |
| UID | 0 | 1000+ |
| 权限 | 不受限制 | 受限制 |

### 最佳实践

- 日常**不要用 root**，创建普通用户
- 需要管理员权限时用 `sudo`
- 每个服务（Docker、Nginx）尽量用自己的用户

### 组的作用

用户可以属于多个组。文件和目录有一个"所属组"。权限三组中的第二组就是这个组。

```bash
groups username     # 查看用户所属的所有组
```

## 实战演示

```bash
# 查看自己
whoami
id

# 创建一个普通用户
useradd -m -s /bin/bash learner
passwd learner
# 输入两次密码

# 查看新用户
id learner
ls -la /home/learner/

# 切换过去试试
su - learner
whoami
pwd
# 应该显示 /home/learner

exit
# 退回 root

# 删掉测试用户
userdel -r learner
```
