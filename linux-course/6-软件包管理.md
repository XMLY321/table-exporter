# 第 6 课：软件包管理

## 目标

学会在 Ubuntu 上安装、更新、卸载软件。

## apt — Ubuntu 的包管理器

### 更新软件源

```bash
apt update              # 刷新软件列表（必须先做）
apt list --upgradable   # 看看哪些可以升级
apt upgrade -y          # 升级所有已安装的包
```

每次安装新软件前先 `apt update`。

### 搜索

```bash
apt search nginx        # 搜索
apt search web server   # 模糊搜索
apt show nginx          # 查看详情
```

### 安装

```bash
apt install nginx -y    # -y = 自动确认，不用手动输入 Y
apt install vim curl git htop   # 一次装多个
```

### 卸载

```bash
apt remove nginx                # 卸载软件（保留配置文件）
apt purge nginx                 # 连配置文件一起删
apt autoremove                  # 删掉不再需要的依赖
apt remove --purge nginx        # 完全清除
```

### 查看已安装

```bash
apt list --installed            # 所有已安装
apt list --installed | grep docker
dpkg -l                         # 另一种查看方式
```

### 清理

```bash
apt clean               # 清理下载的安装包缓存
apt autoremove --purge  # 清理无用依赖
```

## snap — Ubuntu 的另一种包管理器

```bash
snap find lxd           # 搜索
snap install lxd        # 安装
snap list               # 已安装的 snap 包
snap remove lxd         # 卸载
```

Snap 包是自包含的（自带依赖），体积大但隔离性好。当前服务器已有 snap。

## dpkg — 底层包管理

```bash
dpkg -i package.deb     # 安装 .deb 文件
dpkg -l                 # 列出已安装
dpkg -L nginx           # 查看 nginx 安装了哪些文件
dpkg -S /usr/bin/ssh    # 查看文件属于哪个包
```

## 关键概念

### 软件源 (Repository)

APT 从一个叫"软件源"的地址下载软件。源配置在：
```bash
cat /etc/apt/sources.list
# 以及 /etc/apt/sources.list.d/ 目录下
```

### 依赖 (Dependency)

一个软件通常依赖其他软件。比如安装 Docker 需要 `containerd.io`、`docker-ce-cli`。APT 会自动处理依赖。

### PPA — 第三方软件源

```bash
add-apt-repository ppa:xxx/yyy
apt update
apt install some-package
```

## 实战演示

```bash
# 更新系统
apt update

# 安装一个小工具
apt install tree -y
# tree 可以用树形显示目录结构

# 试试 tree
tree /opt/halo -L 1

# 查看 tree 包信息
apt show tree

# 卸载
apt remove tree -y

# 查看已安装包数量
apt list --installed | wc -l
```

## 练习

1. 用 `apt update` 刷新列表
2. 用 `apt list --upgradable` 看看有没有可升级的
3. 安装 `neofetch`（系统信息美化工具），运行它
4. 用 `apt show neofetch` 查看详细信息
5. 卸载 neofetch
